# Slow, Reverb & Bass Cloud Tuner

A Chrome extension that changes the speed, reverb and bass of audio playing in your
browser on soundcloud.com. The popup shows a live visualizer that reacts to the sound,
and its colors follow the speed setting.

Not affiliated with SoundCloud.

## Features
- Speed from 0.5x to 1.5x (pitch follows speed)
- Reverb with a synthetic room and echo
- Bass boost
- Live spectrum visualizer and glow effects in the popup
- Settings are stored locally; nothing is sent anywhere

## Install (unpacked)
1. Open `chrome://extensions` and turn on Developer mode.
2. Click "Load unpacked" and select this folder.
3. Open soundcloud.com, play a track, then click the extension icon.

Or install it from the Chrome Web Store (link coming soon).
